# BUG-2026-08-16T094800: news.automatizems.com 500 HTTPError

## Problem

`https://news.automatizems.com` devolvia `{"status":500,"unhandled":true,"message":"HTTPError"}` em todas as rotas dinâmicas. Estáticos (manifest, sw, favicon) seguiam 200.

## Root Cause Analysis

O domínio é nginx → PM2 `vite dev` em `:3080` no working tree `/home/marce/news`. O PR #6 removeu `migrations/0002` e `0003`. O Vite HMR manteve o glob eager desses arquivos; `db.ts` falhava com ENOENT ao importar auth, e o Start embrulhava isso como HTTPError.

Security impact: NONE (disponibilidade).

Risk level: Medium (site público fora do ar)

## Resolution

- `pm2 restart news` restaurou o site (smoke 200 em `/` e `/api/health`).
- Glob de migrations passou a ser lazy + skip se o arquivo sumir.
